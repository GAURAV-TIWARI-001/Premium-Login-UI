# 🚀 Premium Login UI

A modern and responsive Login UI built using **HTML, CSS, and JavaScript** with a premium glassmorphism design.

## ✨ Features

- 🎨 Modern Glassmorphism UI
- 🌈 Animated Gradient Background
- 🔐 Show / Hide Password
- 📧 Email Validation
- 🔒 Password Validation
- ⚡ Loading Login Button
- ✅ Success Notification
- 📱 Fully Responsive Design
- 💎 Smooth Hover Animations

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
